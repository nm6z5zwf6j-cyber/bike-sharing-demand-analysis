# Велопрокат: когда поездок больше?

Учебный проект для портфолио Junior Data Analyst: исследование почасового спроса на велопрокат Capital Bikeshare в Вашингтоне в 2011–2012 годах. Используются Python и SQLite; анализ воспроизводится без дополнительных библиотек.

## Вопрос

Как различается среднее число аренд по часам в рабочие и нерабочие дни? Набор также позволяет изучить динамику по месяцам и связь с погодой.

## Первые результаты

В источнике 17 379 наблюдаемых часов и 3 292 679 аренд. В рабочие дни максимальное среднее приходится на 17:00 — 525,29 аренды за наблюдаемый час (499 наблюдений); в нерабочие — на 13:00, 372,73 аренды (231 наблюдение). Это исторические наблюдения, а не доказательство причин различий.

Из 17 544 календарных часов двух лет 165 отсутствуют в почасовой таблице. Они не заменяются нулями: неизвестно, почему их нет. Средние рассчитаны только по имеющимся часам. `workingday = 0` объединяет выходные и праздники, поэтому это не только выходные дни.

## Воспроизведение

Установите Python 3.10 или новее и запустите из папки проекта:

```shell
python analyze.py
```

Скрипт скачивает исходный архив, если его нет в `data/source.zip`, проверяет уникальность пары дата–час, неотрицательные значения и равенство общего числа аренд сумме двух групп пользователей. Он выполняет [SQL-запросы](analysis.sql) в памяти и создаёт таблицы `outputs/hourly_demand.csv` и `outputs/monthly_demand.csv`. Интернет нужен только для первоначальной загрузки.

Перед чтением проверяется SHA-256 сохранённого или только что скачанного архива. При несовпадении анализ останавливается до изменения итоговых таблиц; неподходящая загрузка не сохраняется в `data/source.zip`. Если издатель обновит архив, его необходимо отдельно проверить и осознанно обновить контрольную сумму и результаты.

Для проверки без загрузки исходных данных выполните `python -m unittest discover -s tests -v`. Тесты используют синтетический архив: они сверяют результаты SQL с заранее рассчитанными значениями и проверяют отказ на пустых данных, дубликатах часов, несогласованной сумме и неверной контрольной сумме. GitHub Actions запускает их на Windows и Linux с Python 3.10 и 3.12. Исходный полный набор этими тестами не проверяется.

## Источник и ограничения

Источник: Fanaee-T, H. & Gama, J., [Bike Sharing Dataset, UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset), лицензия CC BY 4.0. Авторы также просят ссылаться на публикацию [Event labeling combining ensemble detectors and background knowledge](https://doi.org/10.1007/s13748-013-0040-3). Архив, использованный для расчёта, имеет SHA-256 `b70182d0d0508e9abbb79306ce5c0cec34869000f8220175ac83d11dbe845401`.

Это агрегированные исторические данные, не коммерческий проект. Результаты относятся к источнику за 2011–2012 годы и не описывают текущий спрос. Погода, доступность велосипедов, изменения сервиса и пропуски могут влиять на сопоставимость; причинные выводы не установлены. Данные о погоде присутствуют в исходном архиве, но в первом этапе не анализировались.
